# Roadmap

## Stage 0 - Baseline
Done when:
- Canonical spec exists and tests are placeholders.

## Stage 1 - Ingest adapters
Done when:
- Adapters read input sources and emit canonical lines.

## Stage 2 - Core pipeline
Done when:
- Core processes canonical lines with stable interfaces.

## Stage 3 - Output exporters
Done when:
- Exporters emit structured outputs from core results.

## Stage 4 - Validation
Done when:
- Schema validation and error reporting are reliable.

## Stage 5 - Automation
Done when:
- CI runs lint/test/canon commands and publishes artifacts.
