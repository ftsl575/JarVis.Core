PRINCIPLE: CLEANED SPEC — DELL

ЦЕЛЬ
Cleaned spec предназначен для быстрого и однозначного понимания того,
КАКИЕ КОМПОНЕНТЫ ФИЗИЧЕСКИ УСТАНОВЛЕНЫ В СЕРВЕРЕ ИЛИ ПОСТАВЛЯЮТСЯ С НИМ.

ОСНОВНОЕ ПРАВИЛО
В cleaned spec по умолчанию отображается ТОЛЬКО состав поставки,
а не состояние, режимы или подтверждения конфигуратора.

КЛАССЫ ДАННЫХ

1. ФИЗИЧЕСКИЕ КОМПОНЕНТЫ
Включаются в cleaned spec и идут первыми:
- CPU, Memory, RAID Controllers, NIC, GPU, Drives, PSU, Chassis parts
- Всё, что физически установлено или лежит в коробке

2. НЕФИЗИЧЕСКОЕ (ПО / ЛИЦЕНЗИИ / СЕРВИСЫ)
Отображаются отдельным блоком ниже физики:
- ОС, лицензии, iDRAC features
- Warranty, support, deployment services

3. ОПИСАНИЕ КОНФИГУРАЦИИ (СЛУЖЕБНОЕ)
По умолчанию НЕ является частью cleaned spec:
- No X / Disabled / Decline
- Configuration / Features / Modes
- RAID / Drive / PSU / BIOS configuration
- Regulatory, Shipping, Documentation

Допускается:
- только как служебный хвост
- для диагностики и редких случаев
- не используется в инвойсах и основных документах

ПРИНЦИП ОТСЕЧЕНИЯ
Если строка описывает СОСТОЯНИЕ, РЕЖИМ или ПОДТВЕРЖДЕНИЕ,
а не ФИЗИЧЕСКУЮ ПОСТАВКУ — она не должна мешать просмотру состава сервера.
